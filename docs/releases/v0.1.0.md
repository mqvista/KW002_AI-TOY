# KW002 XiaoZhi v0.1.0

适用于 KW002 玩具的 Tuya T5AI / BK7236 模组，接入官方小智服务器。固件内版本号为 `0.1.0`，TuyaOpen 子模块为 `cdc064e78daeeae598157470244e351cd37cbbed`。

## 本版功能

- 说「小智同学」唤醒后只响提示音，直接进入聆听，不再主动语音问候；支持按 P33 开始对话和语音插话。
- 没有语音播放时关闭功放；播放前开启，缓冲结束后保留 200 ms 尾音余量再关闭，静音时也关闭功放。
- 电池供电且空闲 5 分钟后自动深睡，播放、对话、配网、激活和充电中不睡。深睡后按 P33 唤醒，重新启动联网；深睡期间不支持语音唤醒。
- 可语音查询联网状况、Wi-Fi 名称、局域网 IP 和信号强度，以及通过 HTTPS 按需查询公网 IPv4。
- 保留网页配网、语音播报激活码、电量/电压查询、音量记忆、充电及断网提示。

## 刷写及启动

1. 使用支持 Tuya T5 的烧录工具，选择与设备连接的串口，将 QIO 固件从 `0x0` 写入。保留固件范围之外的授权、校准和 KV 数据，不要整片擦除。
2. 本机 CH343 的 RTS 接到模组复位 CEN；烧录结束务必释放 RTS/DTR 并关闭串口，否则设备可能一直处于复位状态。Windows/CH343 大包发送可能超时，需要使用支持分块发送的工具；本机采用 128 字节分块、460800 波特率完成写入。
3. 日志为 UART0、460800 波特率，仓库内可使用 `python tools/monitor.py -p COM10 -b 460800 -r`。按实际设备修改串口号。
4. 首次开机或长按 P12 约 3 秒进入网页配网，按照提示连接热点并配置 Wi-Fi；如出现激活码，在小智控制台完成绑定。

Windows 下可用 `Get-FileHash <文件路径> -Algorithm SHA256` 核对下载文件；这与 Flash 数据回读校验是不同步骤。
